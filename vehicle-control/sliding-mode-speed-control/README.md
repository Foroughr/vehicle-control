# Sliding-mode vehicle speed control

Longitudinal vehicle speed control with aerodynamic-drag uncertainty diagnostics and boundary-layer sensitivity analysis.

Open this directory as the working folder and add `codes` to the MATLAB path. Inspect `codes/vehicle_setup.m` and `sim4.slx` first; diagnostics are in `codes/run_SMC_diagnostics.m` and `codes/run_SMC_phi_sensitivity.m`. These scripts create output directories and some delete earlier generated figures or logs, so run them on a local copy. MATLAB/Simulink run not verified here.
